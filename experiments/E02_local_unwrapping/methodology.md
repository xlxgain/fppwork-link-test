# E02 方法与来源

依据 Antonopoulos 等 (2015)，DOI [10.1371/journal.pone.0143186](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0143186)，重点阅读模型校正、梯度拟合与常数搜索（式3–8）。本次只实现单窗，不实现论文的 tile 合并。

作者仓库核对到提交 `354cb4b0377dd58eebe6393beb73e581ddd7126e`。已读取 `src/algorithm/least_squares_grad_unwrapper.cpp` 的 SVD、矩形梯度矩阵和张量积基底构造，以及 `src/algorithm/strand_tile_unwrapper.cpp` 的普通前向差代价与偏移搜索。作者代码 Apache-2.0；本项目没有复制作者源代码，仅独立实现任务指定数学适配，因此不分发其源文件。克隆最初超时，随后通过 GitHub API 树及固定提交 raw 文件核对。

W0：仅窗内四邻接 BFS，根为距几何中心最近像素，距离相同时行优先；邻居按行优先索引升序。根级次为0。传播整数级次后以原观测加整数个2π输出。

W1_MLSQU_HEX_Q2：中心化并按坐标标准差缩放，采用 x^a y^b，0≤a,b≤2、排除常数，共8项。对实际端点有限差分建立D，SVD最小二乘拟合包裹梯度。不同于作者矩形实现的解析基函数梯度与其离散梯度算子组合，本适配在六边形有效四邻接边上两侧都用同一有限差分。也不同于双窗M1的6项总次数≤2基底。

rho=2πk/40，k=0…39。残余r=wrap(phi−f0−rho)+rho，代价是有效水平边普通差绝对值均值加垂直边均值，差值不再wrap。作者C++按矩形宽高归一化，这里按实际各向有效边数归一化。并列在绝对代价容差1e−12内取最小k并记录数量；非有限或缺方向失败。输出回投到观测加整数周期，确保不作连续平滑。

算法接口不接收真值、深度、投影坐标或曲面参数；仅使用当前窗口有效像素。空窗、断连、秩亏或病态显式失败。评价器独立计算T_obs和整数误差众数，众数并列取绝对值最小、再较小整数。评价后的对齐量绝不回传。

双窗沿用历史support/estimate，6px半宽和6px端点留白，不改变M0/M1；符号d=c_j−c_i。两窗内部均正确才标unique参考，其他记录保留mu/J/Q与模态差诊断，误差字段NaN。oracle_control单独输出。sigma=0的M1 J只为单位参考信息；非零J采用σφ²=σI²/(2B²)，仅是条件预测。
